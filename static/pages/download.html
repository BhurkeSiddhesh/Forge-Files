Download Forge Files for Windows

The whole toolbox as a Windows app. Every tool runs on your own computer, so your files are never uploaded anywhere and nothing needs an internet connection once it is installed.

Download the latest installer

Windows 10 or 11, 64-bit. The installer is large because it includes everything the tools need to work offline.

Install it in three steps

  1. Download ForgeFiles-Setup from the link above and open it.
  2. If Windows shows a blue Windows protected your PC screen, click More info, then Run anyway. See the next section for why.
  3. Follow the installer. It does not need administrator rights, and it opens Forge Files when it finishes.

Why does Windows show a warning?

Windows SmartScreen warns about any installer that has not been signed with a paid publisher certificate. Forge Files is free and stays free, so we do not buy one. The warning means "this publisher is not known to Microsoft", not "this file is harmful".

You do not have to take our word for it. The code is public, and the installer is built from it by an automated, public build.

Check the installer yourself

Each release lists a SHA-256 checksum next to the installer on the releases page. In PowerShell, run Get-FileHash .\ForgeFiles-Setup-*.exe and compare the result with the checksum on the release page. If they match, you have the exact file the public build produced.

The source code and the build log are both public.

What the app does and does not do

  • It runs a private copy of Forge Files on your computer, reachable only from that computer.
  • Your documents, images and results stay on your disk. Temporary files are deleted automatically.
  • The app may check for updates and announcements. That is a plain download of a small public file and sends none of your files.

Uninstall

Open Settings, then Apps, find Forge Files and choose Uninstall.
