About Forge Files

Practical file tools for everyday document work, with public source code and examples you can inspect before using your own files.

Who maintains the toolbox

Forge Files is maintained through BhurkeSiddhesh on GitHub. The public repository contains the free toolbox, processing utilities and tests. You can report a problem, inspect changes or run your own instance. For support and privacy questions, use our contact page.

What it is designed for

Combine an application packet, keep selected pages from a report, reduce a scan for an upload form, convert a HEIC photo, or move document content into a format another application accepts. The free tools do not require an account or add a branding watermark. File-size, processing and rate limits protect the shared service.

Conversion always needs judgment. A scanned page is different from selectable text; a picture of a slide is different from editable slide objects. Each tool page explains those limits and tells you what to inspect in the result.

Try it before using a private document

Our guides and worked examples include original synthetic files, actual converter outputs, exact sizes and reproduction instructions. Start with a practice file to see how the workflow behaves. The examples demonstrate specific cases, not universal accuracy or compression guarantees.

Where processing happens

Some operations run in your browser when the file is supported. Other operations, including document conversion and OCR, need the server. Browser handlers can fall back to the server for unsupported inputs. Tool pages identify their processing path; the privacy policy explains temporary storage, cleanup and analytics.

Open-source and commercial licensing

The public toolbox is licensed under GNU AGPLv3, with a separate commercial licensing option described in the repository. Read the actual license and licensing information for terms. Public source code makes the implementation inspectable; it does not by itself prove a particular hosted deployment's configuration.

How we maintain the guidance

Instructions are checked against the available controls and implementation. Generated examples use invented data, with measurements taken from actual outputs. AI-assisted drafting is used, followed by implementation and example checks; we do not claim independent expert review. Report outdated instructions or a failed example through Contact.
