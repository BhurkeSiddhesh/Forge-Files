Contact Forge Files

Report a failed conversion, a confusing instruction or an incorrect example. Useful reports help us improve the tools and their guidance.

Report a problem

Open an issue in the public GitHub issue tracker. Include the tool, browser or mobile platform, selected options, the error message and what you expected. A page URL and approximate file type and size are usually enough to start.

Try one of our practice files if you can reproduce the problem without your own document. Public issues are visible to others: do not attach bank statements, identity documents, private contracts, passwords or unredacted personal information.

Email and privacy questions

Email bhurke.siddhesh@gmail.com for questions that should not be public. Support is handled by the project maintainer; no guaranteed response time is offered.

Before reporting a conversion difference

  • Keep the original and compare the downloaded output in another viewer.
  • For a scan, explain whether text can be selected before processing.
  • For a layout issue, describe the affected element: table, font, image or page break.
  • For an upload error, include the visible error text without document contents.

Temporary files cannot serve as backups

Browser outputs and server results are temporary. We cannot promise to recover a deleted file. Download results promptly and keep your originals. See the retention details.
